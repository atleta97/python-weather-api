# Weather API Application

## Overview

This project demonstrates the integration of external APIs into Python applications using weather data.

The application retrieves weather information from the Open-Meteo API, processes JSON responses and presents the results through a modular command-line interface.

The project was completed as part of my independent transition towards computational engineering and scientific programming.

## Features

- Location-based weather search
- Geocoding using API data
- Weather forecast retrieval
- JSON response processing
- Modular function-based structure
- Error handling and input validation
